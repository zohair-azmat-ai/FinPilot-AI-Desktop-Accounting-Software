# Assets

Place branding files here:

| File | Description |
|------|-------------|
| `finpilot-logo.png` | Main FinPilot AI logo (recommended: 840×200px, transparent background) |
| `finpilot-banner.png` | Wide banner image for README header |

To add the logo: export from your design tool and save as `docs/assets/finpilot-logo.png`, then `git add docs/assets/finpilot-logo.png && git push`.
